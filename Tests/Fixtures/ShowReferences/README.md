# Self-test references

These six unmodified, app-rendered 1x checkpoint captures use the procedural placeholder pack
and two disposable targets. They contain only the overlay, no desktop or personal file names.
`scripts/self-test.sh` compares its confirmed show against them with the existing 2 percent
pixel budget. `--update-references` regenerates them when an intentional visual change requires
it; review the resulting images. A reference change must never conceal a failing show.
